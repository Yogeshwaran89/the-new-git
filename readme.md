# Sample Project

A simple web and Python project demonstrating HTML, CSS, JavaScript, and Python fundamentals.

## Project Structure

```
.
├── index.html      # Main HTML file
├── style.css       # CSS styling
├── code.py         # Python script
└── readme.md       # This file
```

## Files Description

### index.html
A sample HTML page that includes:
- Header with welcome message
- Main content section with features list
- Interactive form with JavaScript
- Footer with copyright info

### style.css
Responsive CSS styling including:
- Global styles (reset and defaults)
- Header and footer styling
- Container and button styles
- Hover effects and transitions

### code.py
Python script demonstrating:
- Function definitions
- List operations
- User input handling
- Loop iterations
- Main function pattern

## Getting Started

### Prerequisites
- Python 3.x
- Modern web browser
- Text editor or IDE

### Running the Python Script

```bash
python code.py
```

The script will:
1. Ask for your name and greet you
2. Calculate and display the sum of sample numbers
3. Loop through and display each item

### Opening the Web Page

1. Open `index.html` in your web browser
2. Enter your name in the input field
3. Click the "Click Me!" button to see the greeting
